## Short Description

Select page elements visually and copy a structured prompt with selectors, text, HTML, and React component details.

## Full Description

Selector adds a small launcher to webpages so you can visually pick DOM elements and copy a structured prompt for code editing.

Select one or more elements, add optional per-element instructions, then copy a prompt that includes useful context such as:

- page URL
- CSS selector
- tag name
- visible text
- HTML snippet
- React component chain and debug source when available

Everything runs locally in your browser. Selector has no backend, analytics, tracking, or account requirement.
